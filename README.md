# 万象探险家 Knowledge Explorer · v0.1.8 开发预览

儿童百科科普、闯关和对战游戏。Android Kotlin + Jetpack Compose，独立包名 `com.game.knowledge`，与「数学星球」工程相互独立。整体保留儿童卡通视觉，设置入口、返回导航和退出确认采用自定义的圆角游戏控件，不再使用标准 Material AlertDialog。

## v0.1.8：一年级、二年级适龄古诗题与年级筛选对齐

此前「语文文学」83 道集中于三至五年级。设置按所选年级筛选知识领域，默认一年级时便看不到「语文文学」。最初拟议显示所有领域并在点击时自动切至全部年级，但这种做法会让一年级学生接触高年级题，不符合难度定位。

这次直接参考统编版低年级古诗目录和诗歌内容，增加 50 道手工编写并审核结构的四选一小题：
- **一年级「古诗启蒙」26 道（13 首）**：围绕《咏鹅》《江南》《画》《悯农（其二）》《古朗月行》《风》《春晓》《赠汪伦》《静夜思》《寻隐者不遇》《池上》《小池》《画鸡》，以景物识别、短句接续、浅显含义为主，尽量不涉及文学史。
- **二年级「古诗阅读」24 道（12 首）**：围绕《梅花》《小儿垂钓》《登鹳雀楼》《望庐山瀑布》《江雪》《夜宿山寺》《敕勒歌》《村居》《咏柳》《赋得古原草送别》《晓出净慈寺送林子方》《绝句》，逐渐涉及作者、诗句衔接、场景与直观诗意。
- 题库现在为 **1250 道**，年级分布 **一 226 / 二 224 / 三至六各 200**；「语文文学」增加到 **133 道**。原 1200 道未改动。
- **严格年级过滤**：知识领域只展示当前年级确实有题的分类；不再自动放宽到「全部年级」。在一年级设置中可以直接看到「语文文学」，选择后出现「古诗启蒙」；二年级对应「古诗阅读」。选择领域若与旧的原始题型筛选冲突，会清除冲突题型，不改变年级。
- 补题源文件：`question_bank/source/low_grade_poetry.psv`；导入脚本：`question_bank/merge_poetry_source.py`。在重新从 Excel 导出题库时，`convert_bank.py` 会自动合并，防止后续维护丢失新题。新增题附简单解释与来源索引，保留四选一结构。
- **教材版本提示**：不同年度的统编教材调整个别诗篇在课文、园地或上下册中的位置。本次按一、二年级常见适龄古诗开发练习题，不声称与任何具体学校的教学进度完全一致。选题可再依据实际使用课本做精确化。
- 验证：结构、年级隔离、题目总数、分类题量、题目四个不重复选项、唯一正确答案、解释完整性及构建均需通过。没有连接 Android 实机，设置页的触控需实际复测。

## v0.1.7：修复平板播报开头的短暂卡顿

在 v0.1.6 的可复用音轨、1800ms 音频缓冲、1350ms 预填充基础上，为 PCM 中文朗读增加 **120ms 静音引导 + 25ms 语音淡入**，让首音节避开 AudioTrack.play() 后部分厂商的音频路由启动瞬间。保留原始语音全部内容，只会增加约 120ms 的起播延迟。设置内关闭 PCM 可对比原系统 TTS。
新增 PCM 前导静音、波形保留、帧对齐等测试；此为针对性的工程修复尝试，目前没有连接平板，仍待实机确认。日志可通过 KnowledgeSpeechPcm 的 startupSilenceMs、underrunCount 等字段分析。

题库核查：1200 道题里，「语文文学」83 道，其中「古诗作者」29、「文学作品」20、「传统文学深入」20、「语言文字」14。集中在三年级 43、四年级 20、五年级 20。设置选择「全部年级」→「语文文学」即可看到文学题目。题库本次未改动。

## v0.1.6：按数学星球 v1.3.6 最新修复迁移平板 PCM 输出

在 v0.1.5 的「TTS 合成 WAV → 软件转换 48kHz 双声道 PCM → AudioTrack」路径上优化，不重做语音合成或题库：

- **复用 `AudioTrack.MODE_STREAM`**：单音频线程持有音轨；先预热，逐句播放完后 `stop()+flush()`，正常情况不销毁，下一句话继续使用。坏音轨才重建，关闭应用时确保释放。
- **1800ms 输出缓冲，1350ms 启播前预填充**（48kHz×双声道×16bit 约 345600B 与 259200B）。不足 1350ms 的短句直接把已有数据全部预填，预填充操作不以实时速度等待 1350ms。
- **`THREAD_PRIORITY_AUDIO`**：预热、PCM 转换、流式写入、播放和释放在同一个串行工作线程，降低平板复杂动画、重绘引发的调度干扰。
- **防整句重复播放**：分别记录播放是否真正开始与是否完成；流式输出未发声时可尝试静态 PCM；已经发声的句子即使后端报错也不再从头触发静态 PCM 或系统 TTS。
- **日志**：`KnowledgeSpeechPcm` 记录合成格式、重采样耗时、缓冲大小、实际预填量、朗读耗时、`underrunCount` 增量、音轨创建与异常恢复，方便下一轮实机 ADB logcat 排障。
- 保留平板默认 PCM、可选系统朗读、TTS 缓存、背景音乐降音、原有包名和原签名；不改变已经适配好的横屏布局。
- 添加缓冲边界、失败后不重复播放的 JVM 单元测试和静态回归检查。**仍须在目标 Android 平板上实测；这次的修复策略有数学星球实测反馈，但不能自动视为万象探险家已通过实测。**

## v0.1.5：平板 PCM 语音与横屏全高自适应

### 背景与技术路线
数学星球采用预先准备的 16 kHz PCM 中文数字片段，在应用内转换为 48 kHz 双声道，并优先采用 **750ms AudioTrack MODE_STREAM 输出缓冲、约 562ms 启播前填充**；出现问题会自动尝试静态 PCM。其音频写入、播放、取消及释放串行化，避免跨线程 stop/write 竞态。该方案可解决平板端容易遇到的断续、输出缓冲不足与系统媒体解码卡顿问题。

万象探险家有 1200 道自然语言百科题目，无法直接套用数学星球的固定数字音频词表。因此新增双路线：
- **平板默认 PCM**：设备中文 TTS 调用 `synthesizeToFile` 合成完整 WAV；后台解码 PCM16 并软件重采样到 **48kHz 双声道**；后台单线程 `AudioTrack` 以 750ms 缓冲、562ms 预填充输出，流式失败再试静态模式。缓存最多 80 个已合成语句，减少重复合成；新题切换时以请求代次取消过期播放。
- **系统 TTS 兼容回退**：对不支持文件合成、非 PCM16 WAV 或 PCM 输出失败的设备自动改由系统 TTS 直接播报该句。手机默认沿用系统 TTS。可以在统一设置页手动切换「PCM 缓冲朗读」。
- 保留音乐降音、后台停止语音、关闭播放器等行为，并避免相邻朗读之间无意义的短暂音乐音量回弹。

### 平板横屏
- 根据**当前窗口宽高**决定布局（宽度 ≥720dp、横向、可用高度 ≥450dp），不只检测设备是否叫“平板”，横竖屏/分屏能自动切换。
- 首页在横屏显示三张全高玩法卡片。
- 科普小课堂和知识大闯关：顶部返回/进度固定；左侧插画、右侧题卡**填满剩余高度**；长文字在卡片内部滚动，底部的主要操作控件保持可见。
- AI 对决：玩家答题和 AI 状态并排全高显示；双人对决保持原有分侧旋转逻辑，填满两侧并允许长题目在各自区域内滚动。
- 闯关成绩、知识对决成绩以及科普完成页使用平板横屏结果布局，长错题列表可独立滚动；手机仍采用竖向滚动布局。
- 保留科普 3 秒揭晓和闯关 10 秒跳过限制，没有更改题库及原证书。

### 验证边界
- JVM 单元测试新增对宽高布局阈值、PCM 缓冲/预填充、WAV 读写与格式错误、16kHz→48kHz 重采样、立体声通道的检查。
- 但 Android 真实 TTS 引擎生成的 WAV 格式、厂商 AudioTrack 音频路由、特定分辨率上的滑动触控及实际音质**必须在实体平板上复测**。回退路径是兼容方案，不代表已经证明所有系统均无卡顿。

## v0.1.3：儿童交互、题目解析与背景音乐

- 修复退出确认多余的手动震动：可点击控件已自动触发触感反馈，回调不再重复震动。
- 沿用数学星球的 10 秒解释门槛。**科普模式**每题必须先观察 10 秒才能揭晓答案；**闯关模式**四选一可立即答题，但「跳过看答案」需等待 10 秒。采用 Android 单调时钟，每题独立计时，同时检查按钮可点状态和点击时是否真正达到 10 秒。
- 解析检查覆盖 **1200 道题**：保留 Excel 原文件和导出 JSON 内的 `source_explanation`；儿童显示版使用 `question_bank/explanation_enrichment.py` 与 `specific_notes.py` 生成补充解析。共 1175 道补充或清理，尤其去掉 274 道「对应的正确答案是……」和 40 道判断题转换的编辑说明。所有展示解析不少于 25 字；**不等于逐题完成教师事实审核**。
- 引入数学星球原创生成的 `adventure_loop.wav` 背景音乐和 3 个点击/正确/错误音效。可分别关闭音乐和音效，音乐音量提供 0/25/50/75/100% 档，朗读时音乐降音，切出应用后停止播放。
- 使用带唯一 utterance ID 的中文 TTS 事件防止前一个朗读结束错误解除新一段朗读的音乐压低状态。
- 错题回顾附带解析；完成整轮后 Android 系统返回键直接回首页，不显示「进度将丢失」的误导弹窗。
- 相邻轮次优先从最近未做过的题里抽取，无法满足题数时再补入旧题；每轮仍不会出现重复题。
- 包名、签名身份、各玩法及统一筛选设置保持兼容。

## 玩法

- **科普小课堂**：首页直接进入；题目和类别插画先展示，点击揭晓答案与解析，无需答题。支持上一张、下一张、手动/自动中文朗读。
- **知识大闯关**：首页直接进入；每轮 5/10/20/30 题，随机不重复，四选一作答，立即提示正误、正确答案及解析，结束时显示成绩与错题。
- **知识对决**：首页直接进入；支持横屏平板真人双人同屏，旋转 ±90° 分坐两侧，或挑战 AI。速度优先为同时抢答；正确率优先为独立完成同组题、得分优先，同分比较用时。AI 简单/中等/困难/噩梦随机反应时分别为 6–8、4–6、2.5–4、1.5–2.5 秒。
- **统一设置**：首页统一调整学习年级、知识领域、细分主题、原题来源类型与每轮题数，**所有玩法共享这一套题库筛选**，不再重复进入玩法选择页。对决的对手/赛制/AI 强度是独立设置。以上选择自动本地保存。
- **触觉反馈**：设置中可开关震动；普通按钮轻触、正确答案成功振动、错误答案双脉冲。AI 自动答题不触发玩家设备震动；设备无振动硬件时不会影响应用。
- **中文朗读**：使用设备支持中文的系统 Android TextToSpeech 引擎；未安装引擎仍可正常查看文字。

## 关于「年级」与「难度」

原 Excel 的「星级」并不是独立、全面评定的题目难度，而是基本与年级绑定：一年级、二年级全为 1 星，三、四年级全为 2 星，五、六年级才分为较高星级。如果同时提供年级与最高星级两个筛选，就造成高度重复，并可能莫名排除本年级题目。

因此 **v0.1.3 移除了最高星级筛选和答题页的星级标签**，仅以年级决定知识范围。「幼小衔接」与一年级实际共用相同题目，也合并为一年级；老版本的该设置自动映射到一年级。选择「全部年级」可跨年级探索。

AI 的四档属于**对手强度**而非题目难度。将来只有逐题重新审核并提供独立难度标注后，才恢复真正的难度控制。

## 题库与素材

`question_bank/source/` 原样保留 3 份 Excel，`question_bank/convert_bank.py` 转换出 `question_bank/export/questions.json`，Gradle 自动打包 1200 道（一至六年级各 200）、12 个知识领域、66 个主题、每题 4 个唯一选项的离线题目。

使用最终四选一版为唯一游戏答案来源；原答案版中 40 道判断题在四选一版被有意改写，见 `question_bank/judgment_conversions.json`，不存在其他跨版本意外差异。

采用原创百科书本+放大镜图标，12 类矢量主题插画及按题干匹配的小图示；尚非逐题独立照片。教学内容仍需正式发布前逐题审核。
